# UKP-Labor

Persönliches Laborbuch, Parameter-Rechner und Nachschlagewerk für die UKP-Laserablation (PWA, offline).

**App:** https://additiv3.github.io/UKP-Labor/ · aktueller Stand: **v0.10.0**

- Läuft im Browser und als App auf dem Home-Bildschirm (iPhone: Safari → Teilen → „Zum Home-Bildschirm“).
- Alle Daten bleiben lokal auf dem Gerät. Austausch nur per Export/Import-Datei.
- Funktionen: Logbuch (Versuchsreihen, Versuche, Matrix-Generator), Rechner (Fluenz, Gauß-Strahl, Kaustik,
  Scan-Überlapp, Abtrag, Burst, D²-Fit, Inkubationsfit), Druckansicht für Versuche und Reihen, Anlagen, Material mit Literaturwerten, Notizen mit Markdown/KaTeX.

Dieses Repo dient nur der Auslieferung über GitHub Pages und wird bei jedem Release aktualisiert.
